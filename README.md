# Movie Database Analytics and Visualization

## Overview

This project focuses on the design, management, and analysis of a movie database using Microsoft SQL Server and Python. The database was built from movie-related datasets and was further processed through data cleaning, schema refinement, SQL querying, and visualization techniques.

The project demonstrates practical database management skills, including the use of primary and foreign keys, views, data consistency checks, complex SQL queries, and Python-based data visualization.

## Features

* Database creation and management in Microsoft SQL Server
* Definition of primary and foreign key constraints
* Data cleaning and duplicate removal
* Creation of SQL views for data abstraction
* Complex SQL queries using:

  * JOIN
  * GROUP BY
  * ORDER BY
  * Aggregate functions (COUNT, AVG, MIN, MAX, SUM)
* Data consistency checks and updates
* Python integration with SQL Server using pyodbc
* Data visualization with Matplotlib
* CSV data preprocessing and transformation

## Technologies Used

* Python
* Microsoft SQL Server
* SQL
* pyodbc
* NumPy
* Matplotlib
